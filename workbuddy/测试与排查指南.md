## 四、排查指导（出问题查这里）

### 技能不触发
1. 确认技能已**添加到项目**（不是只全局上传——实测：项目内添加才保证该项目对话触发）
2. 提问要带触发词（见 `使用手册.md` 第五节 skill 触发表）
3. 试**手动调用**：`/技能名` 或 `@技能名`（WorkBuddy 支持的话）
4. 项目内无法直接添加 → 把技能目录**转成 zip** 再上传

### 编排没生效（T3 不过）
1. 确认**项目「指令」字段**已粘贴编排规则（阶段 C ②）
2. 重启 WorkBuddy 再问
3. 仍不行 → 反馈时说明：项目指令贴了吗？在项目新对话问的吗？

### 模型不出现（T4 不过）
1. models.json 放错路径了——`~/.codebuddy/models.json` 和 `~/.workbuddy/models.json` **两个都试**
2. 模型 id 必须和平台完全一致（`deepseek-v4-pro` 等）
3. 改完**重启** WorkBuddy（部分版本支持热更新）
4. 都不行就退回**界面配置**（设置 → 模型 → 添加）

### 检索不到（T5 不过）
1. 元典 key 填对了吗（mcp.json 或界面）
2. 网络通吗
3. 没配检索源时 AI 标 `[待补]` 是**正常降级**，不算错
