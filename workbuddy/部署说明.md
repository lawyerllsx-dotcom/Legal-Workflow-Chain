# WorkBuddy 技能部署说明

> 把 Legal-Workflow-Chain 的技能装到 WorkBuddy 的官方方式。

## 一、本仓库公开的技能（7 个，可直接装）

在仓库根 `skills/` 下，SKILL.md 是 OpenClaw/WorkBuddy 同规范，无需转换：

| 技能 | 目录 |
|------|------|
| 接案评估（入口）| `skills/接案评估/` |
| evidence-catalog-generator | `skills/evidence-catalog-generator/` |
| legal-research | `skills/legal-research/` |
| legal-fact-checker | `skills/legal-fact-checker/` |
| legal-citation-comprehensive | `skills/legal-citation-comprehensive/` |
| docx-editing | `skills/docx-editing/` |
| vision | `skills/vision/` |

## 二、安装方式（官方）

1. WorkBuddy **技能管理 → 添加技能 → 上传技能** → 选技能文件夹（或 zip）
2. 逐个上传这 7 个（或按需）
3. 上传后在「已安装」**启用**

> 部分版本支持复制目录自动识别：复制到 `skills/`（工作区）、`.agents/skills/`（项目）或 `~/.workbuddy/skills/`（全局）。以「已安装」里能出现为准。

## 三、推理层 3 个 skill（不在本仓库）

`dispute-issue-identification` / `deductive-reasoning` / `conflict-resolution` 因来源许可（CC BY-NC-ND）未随仓库分发。

WorkBuddy 用户请按 [推理层接入指南](../docs/推理层-接入指南.md)：
1. 从 [THUYRan/Legal-Skills-Chinese](https://github.com/THUYRan/Legal-Skills-Chinese) 自取原版（个人非商用）
2. 按接入指南本地接线（接力标记 + 五字段）
3. 接好线后同样上传到 WorkBuddy

## 四、部署后

1. 确认「已安装」10 个技能都启用
2. 把 [WORKBUDDY.md](WORKBUDDY.md) 内容粘贴到项目「指令」字段（或存为 `.workbuddy/memory/MEMORY.md`）——这是编排规则
3. **重启 WorkBuddy**，验证：问"接案评估怎么触发"能答出"复杂度三问分流"即生效
