# Legal-Workflow-Chain → WorkBuddy 环境搭建（WorkBuddy 引导式）

> **不用手动一步步做**。你只要把迁移包位置告诉 WorkBuddy，说一句"帮我按这个包搭建环境"，它会读本文件当导师，带你走完全程（含 Obsidian 和本地 OCR）。

---

## 给 WorkBuddy（AI 执行者）的话

你是**环境搭建导师**。用户把迁移包位置告诉你后：

1. **先完整读**：本文件 + `环境配置/` 下三份文档（01 Obsidian / 02 本地 OCR / 03 模型与 Key）
2. **探测环境**：WorkBuddy 是否已装？模型是否已配？技能目录在哪？有没有 Obsidian？
3. **按阶段 A→G 一步步引导**：
   - 能自动做的（复制文件、建目录、写配置骨架）→ **直接做**
   - 需要用户填 key / 手动确认的 → **停下来说明，等用户完成再继续**
4. 每阶段结束确认成功，再进下一阶段
5. 全部完成，引导用户做**阶段 G 验证**

## 给用户（人）的话

打开 WorkBuddy，把工作目录设为**迁移包所在文件夹**，然后说一句：

> 帮我按这个包搭建法律工作流环境，包括 Obsidian 和本地 OCR

WorkBuddy 会带着你一步步来。你要做的只是：回答它的问题、填 key、点确认。

---

## 阶段 A：WorkBuddy 基础
（已装可跳过）
- 下载安装：workbuddy.cn（Windows/macOS）
- 注册登录腾讯账号
- 确认能正常对话

## 阶段 B：模型接入（必填）

- 引导用户去 `环境配置/03` 注册 **DeepSeek**（推荐）或 **GLM**
- 两种配置方式任选：
  - **界面**：WorkBuddy **设置 → 模型 → 添加模型**，填 `base URL + API key + 模型 id`
  - **配置文件**：把 `models.json` 复制到 `~/.codebuddy/models.json` 或 `~/.workbuddy/models.json`（按你的版本选一个目录），填上 key。官方结构为 `models` 数组，字段 `id/name/vendor/url/apiKey/supportsToolCall/supportsImages`
- 确认：随便问一句能正常回答

## 阶段 C：skills + 编排规则

**① 安装技能（官方方式）**：WorkBuddy **技能管理 → 添加技能 → 上传技能**，选中 `skills/` 下的技能文件夹（或对应 zip）逐个上传。上传后在「已安装」确认 11 个技能并**启用**。
> 提示：部分版本也支持直接把 `skills/` 复制到 `skills/`（工作区）、`.agents/skills/`（项目）或 `~/.workbuddy/skills/`（全局）目录自动识别——两种都试，以「已安装」里能出现为准。

**② 编排规则（关键）**：
- **推荐（最官方）**：在 WorkBuddy **新建一个项目**，把 `.workbuddy/memory/MEMORY.md` 的内容**粘贴到项目配置的「指令」字段**——官方确认该字段是"对 AI 的全局行为规则，**所有任务自动继承**"，驱动路由裁决 / 复杂度三问 / F1-F5 / 接案评估自动触发
- **补充**：把本包 `.workbuddy/` 复制到工作目录根，`MEMORY.md` 作为**个人记忆**也会拼入上下文
- 验证：让 WorkBuddy 说一句"接案评估怎么触发"，确认编排已生效

**③ 重启 WorkBuddy**，确认技能 + 编排都生效
- 可选：开启设置「生成对话记忆」，自动积累偏好

## 阶段 D：MCP 检索

- 引导用户注册**元典开放平台**（open.chineselaw.com，法条/案例检索核心源）
- 按 `mcp.json` 把元典 key 填进配置，或在 WorkBuddy **MCP 界面**添加
- （可选）注册 tavily 做联网兜底
- 验证：问一个法条能返回原文 + 条文号

## 阶段 E：Obsidian 知识库（推荐）

- 引导用户读 `环境配置/01`，装 Obsidian + 新建 vault
- 帮用户建 **wiki 目录结构**（checklists/concepts/entities/sources/synthesis/sessions + index/log/overview）+ 把 `WORKBUDDY.md` 放进 vault 根
- 说明知识库三招用法（收材料/查知识/健康检查）

## 阶段 F：本地 OCR（可选，较重）

- 引导用户读 `环境配置/02`
- **说明**：依赖较重（Python 环境 + 约 2.5G 模型），用户可选择跳过——不影响核心 skill
- 若装：`tools/ocr` 工具脚本为作者私有（可向作者索取），或按 02 自行搭建 OpenVINO/PaddleOCR 环境 → 建虚拟环境装依赖 → 下载模型 → 测试一个 PDF

## 阶段 G：验证

- 引导用户跑 `使用手册.md` 第二章「装完第一步先试 3 个」：
  ① 查法条 ② 案件评估 ③ 文书核查
- 三个都能正常 → **环境搭建完成**
